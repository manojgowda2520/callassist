1 · Alexa+ emulator →Talk or type to an Echo Show stand-in. See the real MCP traffic. 2 · Team phones →Your people's phones. They ring, speak and listen, all on this computer. 3 · Call console →Every task, every call and transcript, live.

Everything here runs on this computer. The Alexa+ emulator is a real MCP client that negotiates protocol 2025-03-26 like Alexa+. The MCP server is at /mcp (Streamable HTTP, spec 2025-11-25). Phone calls go over a local phone network with macOS voices; on AWS the same calls go through Amazon Connect and Nova Sonic, which reach CallAssist through the phone-agent tools at /agent/mcp.

Safety: every call starts with an AI disclosure, nothing is called without your explicit yes (checked by the server, not just promised by the AI), only people with a consent record can be called, anyone can say “stop”, calls happen only 8 AM–9 PM in the called person's time zone, tasks about children are declined, and emergencies are sent to 911.
